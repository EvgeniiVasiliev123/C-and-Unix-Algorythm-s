# Алгоритмы и структуры данных

Этот репозиторий посвящён лабораторным работам по курсу **«Алгоритмы и структуры данных»**.
Каждая работа лежит в отдельной папке и содержит исходный код, отчёт (папка `doc`)
и инструкцию по запуску.

## Лабораторные работы

| № | Тема | Папка | Что реализовано |
|---|---|---|---|
| 1 | Алгоритмы сортировки | [lab1-sorting](lab1-sorting) | сортировка подсчётом и сортировка вставкой, обоснование выбора, расчёт затрат по времени и памяти |
| 2 | Структуры данных и динамическое программирование | [lab2-tsp](lab2-tsp) | задача коммивояжёра: алгоритм Дейкстры на графе состояний (битовые маски), проверка полным перебором |
| 3 | Алгоритмы работы с графами | [lab3-traffic](lab3-traffic) | моделирование транспортной системы города: граф перекрёстков, алгоритм Дейкстры, очереди и заторы, сценарии оптимизации |
| 4 | Параллельные алгоритмы | [lab4-parallel](lab4-parallel) | моделирование запросов к серверу: последовательная обработка, subprocess, threads и asyncio |

Отчёты: [ЛР 1](lab1-sorting/doc/report.pdf), [ЛР 2](lab2-tsp/doc/report.pdf), [ЛР 3](lab3-traffic/doc/report.pdf), [ЛР 4](lab4-parallel/doc/report.md).

## Сборка и запуск

Для лабораторных работ 1–3 нужен компилятор с поддержкой C++17 (g++, clang++, MSVC).
Для лабораторной работы 4 нужен Python 3.8 или новее.

```bash
cd lab1-sorting && make run
cd ../lab2-tsp && make run
cd ../lab3-traffic && make run
cd ../lab4-parallel && make run
```

Подробности по каждой работе — в `README.md` соответствующей папки.
