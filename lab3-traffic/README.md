# ЛР №3. Алгоритмы работы с графами: моделирование транспортной системы

**Задача:** по карте центральной части Санкт-Петербурга (52 перекрёстка, два моста через Неву) смоделировать
движение автомобилей в течение суток с утренним и вечерним часами пик, найти самые загруженные участки
дорог и проверить способы устранения заторов.

- **Граф:** перекрёстки - вершины, участки дорог - рёбра (136 направленных участков) с вместимостью и пропускной способностью.
- **Маршруты:** алгоритм Дейкстры (по обратным рёбрам: одна цель - один запуск), в режиме "навигатор" пересчитывается каждую минуту.
- **Модель:** шаг - одна минута, на участках образуются очереди; затор растёт назад по сети, если впереди нет места.
- **Задача 1:** TOP-10 самых загруженных участков: число автомобилей, процент загруженности, длительность загрузки выше 90%, время рассасывания.
- **Задача 2:** сравнение 6 сценариев (навигатор, +1 полоса, светофоры, гибкий график, комплекс).
- **Сложность:** время `O(D·E·log V + T·E + M)` (динамический режим добавляет `O(T·D·E·log V)`), память `O(E·T + A)`.

## Структура

```
lab3-traffic/
├── src/
│   ├── graph.hpp        # перекрёстки, участки, чтение данных, алгоритм Дейкстры
│   ├── sim.hpp          # автомобили, моделирование, показатели участков
│   └── main.cpp         # задача 1 (TOP-10) и задача 2 (сценарии)
├── data/
│   ├── map.png          # исходное изображение
│   ├── nodes.csv        # перекрёстки: id, название, координаты на карте
│   ├── edges.csv        # дороги: перекрёстки, класс (bridge/avenue/street/local), улица
│   └── flows.csv        # группы поездок: откуда, куда, число машин утром / вечером / днём
├── results/             # результаты расчёта (CSV)
├── tools/
│   ├── detect_nodes.py  # поиск перекрёстков на изображении (pillow, numpy, scipy)
│   └── draw_map.py      # карта загрузки и графики (pillow, matplotlib)
├── doc/
│   ├── report.pdf       # отчёт
│   ├── report.md        # тот же отчёт в Markdown
│   └── *.png            # рисунки к отчёту
├── Makefile
└── README.md
```

## Сборка и запуск

Нужен компилятор с поддержкой C++17. Команды выполняются из папки `lab3-traffic`.

```bash
make            # собрать программу traffic
make run        # запустить: результаты печатаются в консоль и сохраняются в results/
make clean      # удалить собранные файлы
```

Рисунки для отчёта (необязательно): `python3 tools/draw_map.py`.

## Входные данные

Все данные придуманы для лабораторной работы и лежат в `data/` в виде CSV, их можно менять:

- `nodes.csv` - `id,name,x,y` (координаты в пикселях изображения `map.png`);
- `edges.csv` - `a,b,class,street`; каждая дорога двусторонняя; класс определяет число полос и скорость;
- `flows.csv` - `from,to,morning,evening,day`; утренний пик с центром в 08:45, вечерний в 18:00.

Подробности и результаты - в [doc/report.pdf](doc/report.pdf).
