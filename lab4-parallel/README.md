# ЛР №4. Параллельные алгоритмы

**Задача:** смоделировать обработку почти одновременно поступающих запросов пользователей на сервер и сравнить последовательный и параллельные способы выполнения.

## Структура

```
lab4-parallel/
├── src/
│   ├── main.py       # четыре способа обработки и измерение времени
│   └── worker.py     # обработчик запросов для subprocess
├── doc/
│   └── report.md     # отчёт
├── Makefile
└── README.md
```

## Запуск

Нужен Python 3.8 или новее. Дополнительные библиотеки не требуются.

```bash
make run
```

Либо напрямую:

```bash
python3 src/main.py
```

Программа запрашивает количества пользователей `U1`, `U2`, `U3` и времена обработки `T1`, `T2`, `T3`. Если оставить поле пустым, используются значения по умолчанию.

## Моделируемые действия

| Действие | Описание | Нагрузка CPU |
|---|---|---:|
| 1 | Регистрация пользователя | 25% |
| 2 | Получение главной страницы | 15% |
| 3 | Просмотр списка пользователей | 1% |

Время обработки имитируется ожиданием (`sleep`), а проценты CPU выводятся как параметры модели. Это учебная имитация времени обслуживания, а не измерение реальной загрузки процессора.
