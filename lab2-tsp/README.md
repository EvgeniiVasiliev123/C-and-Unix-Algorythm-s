# ЛР №2. Структуры данных и динамическое программирование

**Задача:** найти кратчайший замкнутый маршрут (задача коммивояжёра), который начинается в первой
введённой точке, проходит через каждую из остальных точек ровно один раз и возвращается обратно.
Расстояние - евклидово, точки заданы координатами X и Y.

**Решение:** алгоритм Хелда-Карпа (динамическое программирование по подмножествам).

- время `O(n² · 2ⁿ)` (против `(n-1)!` при полном переборе);
- память `O(n · 2ⁿ)`, при этом структуры данных подобраны так, чтобы занимать как можно меньше места
  (битовые маски, таблица `float` без таблицы родителей, фиксированная стартовая точка).

## Структура

```
lab2-tsp/
├── src/
│   ├── tsp.hpp      # структуры данных, алгоритм ДП, полный перебор для проверки
│   ├── main.cpp     # ввод точек, запуск, вывод маршрута
│   └── test.cpp     # проверка ДП полным перебором на случайных данных
├── data/
│   └── example.txt  # пример входных данных (8 точек)
├── doc/
│   └── report.pdf   # отчёт
├── Makefile
└── README.md
```

## Сборка и запуск

Команды выполняются из папки `lab2-tsp`.

```bash
make            # собрать программу tsp и тесты
make run        # решить пример из data/example.txt
make test       # проверить ДП полным перебором (1800 случайных тестов)
make clean      # удалить собранные файлы
```

Запуск вручную:

```bash
./tsp data/example.txt     # точки из файла
./tsp --random 15          # 15 случайных точек
./tsp                      # точки из стандартного ввода (завершить Ctrl+D)
```

## Формат входных данных

Одна точка в строке. Допустимы записи `X Y`, `номер X Y` или `Точка 1, X, Y`. Строки, начинающиеся
с `#`, считаются комментариями. **Первая точка - начало и конец маршрута.**

```
# номер X Y
1 0 0
2 4 0
3 8 1
```

## Ограничения

Максимум 22 точки (`MAX_POINTS` в `src/tsp.hpp`): таблица ДП для 22 точек занимает около 168 МБ,
для 25 точек потребовалось бы около 1,5 ГБ. Подробные расчёты - в [doc/report.pdf](doc/report.pdf).
