# ЛР №2. Структуры данных и динамическое программирование

Решение задачи коммивояжёра (TSP) методом динамического программирования **Held–Karp**.

## Постановка задачи

Даны точки на плоскости с координатами `(X, Y)`. Требуется построить кратчайший замкнутый маршрут: начать в первой введённой точке, посетить каждую другую точку ровно один раз и вернуться в начало. Расстояние между точками — евклидово.

## Реализация

- `src/tsp.hpp` — типы `Point` и `TspResult`, матрица евклидовых расстояний, DP Held–Karp и восстановление маршрута по `parent`; полный перебор используется только как эталон в тестах.
- `src/main.cpp` — чтение координат из файла или stdin, генерация случайного набора, вывод маршрута и его длины.
- `src/test.cpp` — проверка оптимальности относительно полного перебора.
- `data/example.txt` — пример из восьми точек.
- `doc/report.md` — отчёт с описанием структуры, алгоритма и оценками сложности.

## Сборка и запуск

Нужен `g++` с поддержкой C++17. Из каталога `lab2-tsp`:

```bash
make          # собрать программу и тесты
make run      # запустить на data/example.txt
make test     # выполнить 1805 проверок
make clean    # удалить исполняемые файлы
```

Ручной запуск:

```bash
./tsp data/example.txt
./tsp --random 12
./tsp                 # координаты из stdin; завершить Ctrl+D
```

## Формат входных данных

Одна точка на строку. Поддерживаются `X Y`, `номер X Y` и строки вида `Точка 1, X, Y`. Строки, начинающиеся с `#`, игнорируются. Для каждой строки используются два последних числовых значения как координаты. Первая точка — старт и финиш.

## Ограничение

Поддерживается от 1 до **18 точек**. Для Held–Karp время `O(n² · 2ⁿ)`, память `O(n · 2ⁿ)`; при 18 точках таблица DP и таблица предков занимают примерно 40.5 MiB без учёта небольших накладных расходов.

Подробное описание решения и результаты проверки: [doc/report.md](doc/report.md).
