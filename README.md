# ЛР №1. Алгоритмы сортировки

Лабораторная работа по курсу «Параллельное программирование».
Цель: познакомиться с основами анализа алгоритмов на примере сортировок.

## Структура репозитория

```
.
├── src/
│   ├── sort1_counting.cpp   # [СОРТ 1] сортировка подсчётом
│   └── sort2_insertion.cpp  # [СОРТ 2] сортировка вставкой
├── doc/
│   └── report.md            # отчёт: постановка задач, выбор алгоритмов, расчёты
├── Makefile
└── README.md
```

## Сборка и запуск

Нужен компилятор с поддержкой C++17 (g++, clang++, MSVC).

```bash
make          # собрать обе программы
make run      # собрать и запустить
make clean    # удалить собранные файлы
```

Без make:

```bash
g++ -std=c++17 -O2 src/sort1_counting.cpp -o sort1 && ./sort1
g++ -std=c++17 -O2 src/sort2_insertion.cpp -o sort2 && ./sort2
```

## Кратко

| Шаг | Алгоритм | Задача | Время | Память |
|---|---|---|---|---|
| СОРТ 1 | Подсчётом | Сортировка 100 000 оценок (0..100) | O(n + k) | O(k) |
| СОРТ 2 | Вставкой | Обновление почти отсортированного рейтинга | O(n²), на почти отсортированных O(n + I) | O(1) |

Подробности и расчёты - в [doc/report.md](doc/report.md).
