# ЛР №2. Структуры данных и динамическое программирование

**Задача:** найти кратчайший замкнутый маршрут (задача коммивояжёра), который начинается в первой
введённой точке, проходит через каждую из остальных точек ровно один раз и возвращается обратно.
Расстояние - евклидово, точки заданы координатами X и Y.

**Решение:** алгоритм Дейкстры на графе состояний. Состояние = (какие точки уже посещены, в какой точке
мы стоим). Кратчайший путь от начального состояния до состояния "посетили все и вернулись домой" -
это и есть оптимальный маршрут.

- структура данных: битовая маска посещённых точек + массивы `dist` и `parent` по номеру состояния;
- время `O(n³ · 2ⁿ)`, память `O(n · 2ⁿ)` (против `(n-1)!` при полном переборе).

## Структура

```
lab2-tsp/
├── src/
│   ├── tsp.hpp      # структуры данных, алгоритм Дейкстры, полный перебор для проверки
│   ├── main.cpp     # ввод точек, запуск, вывод маршрута
│   └── test.cpp     # проверка Дейкстры полным перебором на случайных данных
├── data/
│   └── example.txt  # пример входных данных (8 точек)
├── doc/
│   └── report.pdf   # отчёт
├── Makefile
└── README.md
```

## Сборка и запуск

Команды выполняются из папки `lab2-tsp`. Нужен компилятор с поддержкой C++17.

```bash
make            # собрать программу tsp и тесты
make run        # решить пример из data/example.txt
make test       # проверить алгоритм полным перебором (1800 случайных тестов)
make clean      # удалить собранные файлы
```

Запуск вручную:

```bash
./tsp data/example.txt     # точки из файла
./tsp --random 12          # 12 случайных точек
./tsp                      # точки из стандартного ввода (завершить Ctrl+D)
```

## Формат входных данных

Одна точка в строке: `X Y`, `номер X Y` или `Точка 1, X, Y`. Строки, начинающиеся с `#`, - комментарии.
**Первая точка - начало и конец маршрута.**

## Ограничения

Максимум 15 точек (`MAX_POINTS` в `src/tsp.hpp`): число состояний растёт как `n · 2ⁿ`.
Подробные расчёты - в [doc/report.pdf](doc/report.pdf).
