# ЛР №4. Параллельные алгоритмы

**Задача:** смоделировать обработку почти одновременно поступающих запросов пользователей на сервер и сравнить последовательный и параллельные способы выполнения.

## Структура проекта

```
lab4-parallel/
├── src/
│   ├── main.py       # основная программа: четыре способа обработки
│   └── worker.py     # обработчик для дочерних процессов
├── colab/
│   └── lab4_parallel_colab.ipynb  # готовый ноутбук для Google Colab
├── doc/
│   └── report.md     # отчёт по лабораторной работе
├── Makefile
└── README.md
```

## Запуск на компьютере

Нужен Python 3.8 или новее. Дополнительные библиотеки устанавливать не нужно.

Из папки `lab4-parallel`:

```bash
python3 src/main.py
```

Или, если установлен Make:

```bash
make run
```

Программа запросит количество пользователей для каждого действия и время обработки одного запроса. Если просто нажать Enter, будут использованы значения по умолчанию.

## Запуск в Google Colab

Откройте файл [lab4_parallel_colab.ipynb](colab/lab4_parallel_colab.ipynb) в репозитории и нажмите **Open in Colab** (или скачайте ноутбук и загрузите его в Google Colab).

В ноутбуке все четыре способа обработки уже реализованы. Для изменения эксперимента отредактируйте значения `USER_COUNTS` и `REQUEST_TIMES` в первой ячейке с кодом. Ничего дополнительно устанавливать или загружать не требуется.

## Моделируемые действия

| Действие | Описание | Нагрузка CPU по условию |
|---|---|---:|
| 1 | Регистрация пользователя | 25% |
| 2 | Получение главной страницы | 15% |
| 3 | Просмотр списка пользователей | 1% |

Время обработки имитируется ожиданием `sleep`. Проценты CPU показываются как параметры модели: программа не измеряет и не создаёт фактическую загрузку процессора. Поэтому эксперимент сравнивает способы организации одновременного ожидания запросов, а не скорость CPU-вычислений.
